## التشغيل

1. **Settings ← Pages**: اختار الفرع (Deploy from a branch) والمجلد `/ (root)`.
2. **تحديث الأخبار**: الـ Action (`fetch-feeds`) بتشتغل كل ساعة، ويدويًا من تبويب Actions ← fetch-feeds ← Run workflow.
   الجدولة بتشتغل بس من الفرع الافتراضي (`main`) — فادمج الفرع في `main` الأول.
   Settings ← Actions ← General ← Workflow permissions: **Read and write**.
3. افتح الموقع ← **الإعدادات** وحط مفتاح ElevenLabs وأرقام الأصوات. المفاتيح بتتحفظ في متصفحك بس.

التصدير محتاج Chrome أو Edge على الكمبيوتر (H.264 + AAC).

## الوسائط والوسيط (Cloudflare Worker)

بحث الوسائط بيشتغل من المتصفح مباشرة. لكن **تحميل الملف نفسه** بيتفحص من GitHub Actions وطلع:

| المصدر | تحميل الملف من المتصفح |
|---|---|
| Wikimedia Commons، Openverse (Flickr) | ✅ شغّال من غير إعداد |
| NASA، Internet Archive، Pixabay | ❌ بيمنعه (CORS) — محتاج «الوسيط» |

الوسيط مجاني وبيتعمل مرة: `dash.cloudflare.com` ← Workers & Pages ← Create ← Hello World ← Edit code ← ألصق `tools/cors-proxy-worker.js` ← Deploy ← انسخ الرابط وحطه في الإعدادات (رابط الوسيط). لو عملته قبل كده للصوت، ألصق النسخة الجديدة (فيها مواقع الوسائط).
مفتاح Pixabay المجاني من `pixabay.com/api/docs`.

التراخيص: الأداة بتقبل ملك عام / CC0 (من غير شرط) وCC BY / BY-SA وPixabay (النسب بيظهر على الشاشة)، وبترفض أي NC أو ND أو ترخيص مش واضح. صور CDC/NOAA/الجهات الحكومية: حمّلها من موقعها وارفعها، أو الصق الرابط المباشر في «إضافة وسيط برابط مباشر» مع الحقوق.

## المصادر

`config/sources.json` — عدّله براحتك (RSS رسمية، وقنوات يوتيوب بالـ handle). مصدر بيفشل بيتخطّاه الـ Action
وبيظهر اسمه في شاشة الأخبار. روابط RSS الافتراضية لازم تتراجع (مش متحققة من جوه الجلسة).

## قواعد ثابتة

- أي معلومة في الريل لازم لها **مصدر أصلي** (اسم + رابط) على الشاشة. اليوتيوبر مش مصدر.
- مفيش صور من المواقع الإخبارية، ومفيش صور لشخصيات سياسية.
- الريل الطبي بيظهر عليه تنبيه «معلومة عامة وليست استشارة طبية».
- السكريبت بأسلوبك؛ الأداة مبتكتبهوش بدالك.
